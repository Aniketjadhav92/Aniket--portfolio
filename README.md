# Aniket Jadhav - Portfolio (React + JavaScript)

A modern portfolio website built with React and JavaScript (converted from TypeScript).

## Getting Started

```bash
npm install
npm run dev
```

## Build for Production

```bash
npm run build
npm run preview
```

## Tech Stack

- **React 18** with JavaScript (JSX)
- **Vite** for build tooling
- **Tailwind CSS** for styling
- **shadcn/ui** components
- **React Router** for navigation
- **Lucide React** for icons
